CALVARY MINISTRIES WEBSITE
===========================

Open index.html in a browser to view the website.

Included:
- Responsive mobile/desktop design
- Your supplied church photos
- Sunday service details
- Click-to-call phone buttons
- Google Maps embed and directions button
- John 3:16 Bible quote
- Gallery section

To publish:
1. Upload the entire folder contents to a web host (for example GitHub Pages, Netlify, Vercel, or your existing hosting).
2. Keep the images folder next to index.html.

The map uses the exact Google Maps link supplied for the directions button and a Google Maps embed query for the displayed map.
